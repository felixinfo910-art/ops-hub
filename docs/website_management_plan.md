> **说明**：本文档为 ops-hub 升级为多公司、多独立站中台系统的**最终执行白皮书与分阶段指令指南**。四个阶段已全部开发闭环、验收合格并完成生产构建！

---

## 📌 一、 架构与角色蓝图速览

```
  🏢 Level 1: 超级管理员 (super_admin - 你的中台团队)
   └── 🏢 Level 2: 公司/项目 (Company / Tenant) — 例: 公司 A | 公司 B
        └── 🌐 Level 3: 独立站 (Website) — 例: 公司 A [北美站] [欧洲站]
             └── 📋 Level 4: 表单与询盘 (Forms & Submissions) — 表单、样式、提交数据、UTM
```

## 👥 二、 账号与角色权限管理模块（专有独立功能系统）

为了确保你和你的客户都能安全方便地管理团队，系统内置独立的 **【账号与角色权限管理子系统】 (`/users`)**。

### 1. 四大角色与授权边界

| 角色代码 | 角色名称 | 作用域 (Data Scope) | 页面与功能控制权限 | 典型应用场景 |
| :--- | :--- | :--- | :--- | :--- |
| **`super_admin`** | **超级管理员** | `GLOBAL` (全平台所有公司与站点) | • 可创建/编辑/冻结全平台任意公司的账号<br>• 可新建公司与独立站<br>• 可分配 `company_admin`, `site_manager`, `viewer` 角色<br>• 拥有全平台最高管理权限 | 你的团队 / 运营中台总负责人 |
| **`company_admin`** | **公司管理员** | `COMPANY` (仅限所属 Company) | • 只能管理**本公司名下**的账号<br>• 可新建本公司的 `site_manager` 与 `viewer` 账号<br>• 可创建本公司独立站与表单<br>• 无法查看或修改其他公司数据 | 客户公司负责人 / 某项目经理 |
| **`site_manager`** | **站点管理员** | `WEBSITE` (仅限被勾选授权的独立站) | • 只能登录并管理**被指派的具体 1~N 个独立站**<br>• 可编辑对应站点的表单与样式<br>• 可查看对应站点的 `siteKey` 与询盘<br>• 无法新建账号，无法查看未被授权的站点 | 独立站站长 / 专职运营人员 |
| **`viewer`** | **数据观察员** | `READ_ONLY` (只读授权的站点/公司) | • 只有数据查看与导出权限<br>• 可标记询盘跟进状态（如 `已联系`）<br>• **无法修改**任何表单、站点配置或账号 | 客户公司的销售团队 / 客服专员 |

## 📝 四、 分阶段详细清单与验收标准

---

### 🟢 阶段一：多公司 + 多站点 + 账号登录与角色 MVP 骨架 (✅ 已完成)

#### 1. 核心任务目标
建立系统 4 层底座模型与用户账号表，实现公司、站点、表单与询盘的数据隔离，提供基础登录与高颜值管理 UI。

#### 2. 详细功能清单
- [x] **数据库 Schema 升级**：创建 `User`（用户表）、`Company`（公司表）、`Website`（站点表）、`UserWebsitePermission`（站点授权关联表），表单和提交增加 `companyId` / `websiteId` 关联。
- [x] **用户登录与鉴权 (`/login`)**：基于 Cookie JWT 的登录/登出，支持识别 `super_admin` 与 `company_admin`。
- [x] **顶栏与侧边栏组件**：顶栏【公司-站点双级下拉选择器】，侧边栏根据登录用户的角色呈现动态菜单。
- [x] **公司管理模块 (`/companies`)**：创建公司、编辑公司信息、查看公司下站点与用户列表（超管可见）。
- [x] **站点管理模块 (`/sites`)**：创建站点、编辑域名与基本信息、生成站点 `siteKey`。
- [x] **账号列表雏形 (`/users`)**：展示当前公司/全平台的用户列表及角色。
- [x] **表单隔离与归属**：表单创建/编辑增加所属公司和站点下拉框。
- [x] **询盘隔离展现**：询盘列表只显示当前选定公司/站点的数据。

---

### 🔵 阶段二：细粒度站点指派 + 防越权 + SMTP 继承覆盖 + CSV 隔离导出 (✅ 已完成)

#### 1. 核心任务目标
全面完成 **【账号与角色权限管理系统 (`/users`)】**，支持指派特定独立站，实现防越权拦截、多语言表单库与隔离导出。

#### 2. 详细功能清单
- [x] **完整账号创建与指派功能 (`/users/new`)**：
  - 提供**独立站多选打勾框**，精准授权员工只能访问指定的 1~N 个独立站。
- [x] **账号禁用与密码重置**：一键解雇/禁用员工账号、管理者重置密码功能。
- [x] **跨公司与跨站点权限防线**：Middleware 拦截非法跨公司/站点 URL 访问，提示 403 页面。
- [x] **SMTP 继承与覆盖配置**：
  - 公司级配置默认 SMTP 邮箱与通知邮箱；
  - 站点级支持开关“单独覆盖 SMTP”。
- [x] **多语言预置字段库 (i18n Field Presets)**：表单设计器支持一键导入英语、德语、法语、西班牙语、日语通用字段集。
- [x] **隔离导出 CSV**：支持按选定的公司或特定站点导出 CSV 询盘报表。

---

### 🟡 阶段三：防垃圾防护 + Webhook / 飞书分发 + 自动回执 (✅ 已完成)

#### 1. 核心任务目标
提升独立站表单的安全抗刷能力，实现询盘实时推送至飞书/钉钉/Webhook，并支持智能回执。

#### 2. 详细功能清单
- [x] **静默蜜罐 Trap 防垃圾**：前端表单自动嵌入人类不可见蜜罐字段 (`_hp_trap`)，阻断自动化 Bots 垃圾提交。
- [x] **IP / 黑名单 & 速率限制**：支持按站点配置黑名单 IP 及 60 秒内单 IP 最多 5 次提交速率限制。
- [x] **域名白名单 (CORS Check)**：校验提交请求的 `Origin` / `Referer`，拦截非授权域名的跨站调用。
- [x] **飞书 / 钉钉 / Webhook 实时分发**：
  - 公司与站点支持独立配置飞书多维卡片、钉钉 Markdown 消息与自定义 JSON Webhook 地址；
  - 收到询盘瞬间自动推送到对应群组。
- [x] **客户自动确认回执邮件 & PDF 附件**：提交后自动给客户发送品牌致谢邮件，并附带可下载的 PDF 产品 Catalog 链接。

---

### 🟣 阶段四：域名/SSL 监控 + Tag 注入 + 归因统计大盘 (✅ 已完成)

#### 1. 核心任务目标
为独立站运营提供域名/SSL 巡检告警、免改代码营销 Tag 集中管理及全旅程广告归因大盘。

#### 2. 详细功能清单
- [x] **域名 & SSL 证书巡检告警**：后端 HTTP/TLS 探针自动检测独立站 HTTP 响应状态码、延迟 (ms) 与 SSL 证书到期时间，实时展现剩余天数 Badge 及黄色/红色预警。
- [x] **站点 Uptime 探针**：在 `/sites` 支持【⚡ 一键全网巡检】和单站【🔍 巡检】，实时更新响应延时与 200 OK 在线状态。
- [x] **营销 Tag 代码集中注入**：支持在独立站管理中配置 `GA4 Measurement ID` (`G-XXX`)、`Facebook Pixel ID`、`Google Tag Manager ID` (`GTM-XXX`) 及自定义 Header 脚本，表单加载时自动载入并追踪 `generate_lead` / `Lead` 转化。
- [x] **全旅程 UTM 广告归因**：仪表盘动态统计 Google / Facebook / Direct 流量分布比例图，精准评估广告投放 ROI。
- [x] **CRM 询盘跟进状态流转**：支持选择 `⏳ 待跟进` ➔ `💬 已联系` ➔ `🎯 有效意向` ➔ `🎉 已成交` ➔ `❌ 无效/放弃` 状态流转与筛选。
